# TNV Leadership Selection Portal

A client-side web application for Tamil Nadu Volunteers (TNV) to conduct structured leadership interviews and manage candidate profiles.

## Features

- **Interviewer Portal**:
  - Live 16 bilingual (English/Tamil) question assessment wizard.
  - Interactive scoring (0 / ½ / 1) with collapsible "What to Look For" tips.
  - Automatic suggested role allocation based on scoring bands.
  - Excel sheet export of candidates evaluated within the session.

- **Admin Portal**:
  - Secure entry using core administration credentials.
  - Real-time dashboard with overview stats.
  - Consolidated view of all candidate evaluations across all interviewers (persisted via localStorage).
  - Single-click Excel export of the full candidate database.

- **Design**:
  - Elegant light theme with forest green and gold official branding.
  - Responsive design optimized for desktop and mobile tablets.
